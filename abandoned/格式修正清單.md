## ③ 表格儲存格 `<br>` + 清單 → 拆出（PRD.md，34 列）

Notion 表格儲存格是純文字，裝不下換行/清單。受影響行號：

```
34, 45, 46, 47, 59, 60, 61, 69, 70, 71, 79, 80, 81, 89, 90, 91,
99, 100, 101, 109, 110, 111, 119, 120, 121, 122, 132, 133, 134, 135
```

分兩種處理：

### 3a. 短欄位（line 34）— 換行改成逗號或分列

```markdown
修正前：| **核心團隊** | PM: TBD<br>Lead Engineer: TBD<br>UX Designer: TBD |
修正後：| **核心團隊** | PM: TBD / Lead Engineer: TBD / UX Designer: TBD |
```

### 3b. 含清單的大儲存格（line 45-47, 132-135）— 整段移出表格

```markdown
修正前（line 45）：
| **1. 背景與痛點** | **市場規模**：...<br><br>**核心痛點**：<br>- **案主端**：...<br>- **接案者端**：... |

修正後：
**1. 背景與痛點**

**市場規模**：...

**核心痛點 - 信任赤字**：
- **案主端**：付了錢拿不到東西、交付物不符預期、接案者失聯
- **接案者端**：做了事收不到錢、需求無限修改、案主不回應
- **雙方**：需求溝通困難、驗收標準模糊、爭議處理無門
```

### 3c. 使用者故事表（line 59-122，US-101 ~ US-704）— 整段從表格改清單

這批 24 列每格都是 `As a... <br>I want to... <br>so that...` + 允收標準清單，**整個 User Story 區段建議從表格改成標準清單呈現**：

```markdown
修正前：
| **US-101** | **As a** 新使用者,<br>**I want to** 透過電子郵件註冊帳號,<br>**so that** 我可以開始使用平台服務。 | 1. 成功註冊<br>2. 收到驗證信<br>3. 點擊驗證連結啟用<br>4. 選擇身份 |

修正後：
**US-101**
- **As a** 新使用者
- **I want to** 透過電子郵件註冊帳號
- **so that** 我可以開始使用平台服務

允收標準：
1. 成功使用有效 Email 註冊
2. 收到驗證信件
3. 點擊驗證連結後帳號啟用
4. 選擇身份類型（案主/接案者/兩者皆是）
```
