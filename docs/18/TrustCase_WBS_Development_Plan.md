### 🛠️ 技術選型

| 層級 | 技術選擇 | 理由 |
|------|----------|------|
| **Frontend** | Next.js 14 (App Router) | SSR/SEO、React 生態、Vercel 部署方便 |
| **Backend** | NestJS (TypeScript) | 強型別、模組化、適合中大型專案 |
| **Database** | PostgreSQL 15 | ACID、JSON 支援、成熟穩定 |
| **Cache** | Redis 7 | Session、Rate Limiting、Queue |
| **Storage** | AWS S3 / GCP GCS | 交付物檔案、成本低 |
| **Payment** | 綠界 ECPay | 台灣在地、信用卡+ATM+超商 |
| **Auth** | NextAuth.js + JWT | OAuth 整合方便 |
| **Queue** | BullMQ (Redis) | 非同步任務（放款、通知） |

## 7. 專案管控機制

- **日報**: 開發團隊 Standup 同步

### 🔄 變更管控流程
1. **變更請求提交** → 2. **影響評估（工時/依賴）** → 3. **PM/TL 審核** → 4. **批准/拒絕** → 5. **WBS 更新與追蹤**

- **關鍵路徑優先**: 金流整合、里程碑託管為 P0

- **技能匹配**: 根據團隊成員專長分配任務
